# Փոթորիկ · Potoreek

The living archive of the Armenian liberation struggle: stories, poems, quotes,
videos and books from the Fedayi era, in Armenian and English.

## Run it locally

```bash
npm install
npm run dev
```

## Publish

The site is hosted on Netlify at https://potoreek.com. Every push to the `main`
branch on GitHub builds and publishes it automatically (`netlify.toml` holds
the settings).

## Content

All content is in `public/data/`. See `CLAUDE.md` for the file layout.
